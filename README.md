# Hotel Booking Data Analysis & Cancellation Prediction

This project helps hotel businesses analyze booking data, reduce cancellations, and improve revenue using data analytics and machine learning.
- Python: Pandas, NumPy, Matplotlib, Seaborn, Scikit-learn, XGBoost
- SQL
- Power BI
- Google Colab

## Project Overview
This project analyzes hotel booking data to understand customer behavior, cancellation patterns, hotel performance, revenue, payments, and operational insights.

## Key Results
- Cleaned the dataset from 119,390 rows to 86,639 rows
- Overall cancellation rate: 27.7%
- Peak month: August
- XGBoost model accuracy: 81.8%
- ROC-AUC: ~0.88
- Room upgrades reduced cancellation rate from 31.6% to 4.8%

## Files
- `hotel_bookings_EDA_.ipynb` — Python EDA and ML notebook
- `FinalProjectSQL (1).sql` — SQL analysis queries
- `Cancellation Analysis Dashboard.pbix` — Power BI dashboard
- `final_hotel_EDA&SQL_report (1).pdf` — Final project report

## Business Value
This project helps hotel management identify high-risk bookings, understand cancellation drivers, improve revenue decisions, and monitor hotel performance through dashboards and analytics.
